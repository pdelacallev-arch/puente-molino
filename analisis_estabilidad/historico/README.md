# Resultados históricos de estabilidad

Esta carpeta conserva las salidas anteriores a los contratos modulares.

- `outputs_raiz/`: antiguas carpetas `outputs/calc_est_2026_*`.
- `outputs_locales/`: resultados antes generados dentro del código.
- `imagenes/`: figuras históricas de interfaces.
- `reporte_subestructura.md`: reporte que antes se escribía junto al script.

Estos archivos se consideran `LEGADO_NO_REPRODUCIBLE` cuando no cuentan con
una entrada resuelta y huellas de dependencias. No deben utilizarse como
entrada de cálculos nuevos sin una validación e importación explícitas.
